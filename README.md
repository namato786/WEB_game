# Phaser Survival Game

Simple 2D game built with Phaser 3.

## Controls
- Arrow Keys → Move
- F → Fireball (max 5)
- H → Heal (5s cooldown)
- SHIFT → Dash

## Features
- Enemy AI (movement + charge + attack)
- Fireball skill system
- Health & score system
- Camera follow

## Run
Just open index.html with Live Server
